# Shayaan Shaikh – Portfolio Website

A modern personal portfolio website built with HTML and TailwindCSS, featuring smooth navigation, a dark aesthetic, and sections that highlight my work, hobbies, and contact information.

---

## Features

### Dark Modern UI
A sleek black and slate theme with red accents for contrast.

### Fixed Navigation Bar
- Smooth scrolling  
- Centered rounded navigation bar  
- Red hover effects  

### Home Section
- Arabic name display: شایان  
- Pronunciation guide  
- Meaning of the name  

### About Me
Includes details about:
- Background  
- Engineering mindset  
- Photography  
- Music  
- Projects:
  - Nap-Pad  
  - PCB Board Workshop  
  - Task-Topper  

### FAQ Section
Expandable Q&A using HTML `<details>` components.

### Testimonials
Quote cards from peers and mentors.

### Stats
Progress bars displaying:
- Photos taken  
- Photos edited  

### Contact Section
Links to:
- Personal website  
- Email  
- Instagram  

### Spotify
Two embedded widgets:
- A preferred track  
- A preferred album  

---

## Tech Stack
- HTML5  
- TailwindCSS (via CDN)
